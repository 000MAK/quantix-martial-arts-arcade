# Quantix Martial Arts Arcade

- `index.html`: Quantix Martial Arts Analytics landing page and 100-discipline catalogue.
- `quantix-bjj-game/index.html`: **QUANTIX BJJ: Roll & Submit**, a self-contained browser game (canvas graphics, Web Audio, three AI levels, five-minute match, stamina/posture HUD). Open the file in a browser; no build step.
- `quantix_ma/`: small Markov / semi-Markov transition-model prototype for BJJ position sequences. Without a labelled data file it runs on synthetic sequences and marks its report `synthetic`.

The semi-Markov analysis project lives in its own repo: [quantix-bjj-semi-markov](https://github.com/000MAK/quantix-bjj-semi-markov).

Nothing here is trained on real fight video. MIT licensed.
